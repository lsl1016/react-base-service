# 新增运行时设置在线配置（管理面板）

## 1. 背景与目标

subagent 委派策略此前只能改 `custom.yaml` 并重启生效，运营期无法在线调整。本次引入「运行时设置」资源：管理面板「运行时配置」Tab 在线覆盖 yaml 策略，取值优先级为 **DB 覆盖 > custom.yaml > 内置默认值**（字段级），yaml 始终兜底，删除覆盖即回到纯 yaml 行为。

## 2. 代码改动

- `models/llm/runtime_setting.go` + `sql/runtime_setting_v1.sql`（init.sql 同步补表）：新表 `tblLlmRuntimeSetting`，`setting_key` 单行 JSON（当前仅 `subagent`，预留扩展位），带 `updated_by` 审计。
- `conf/runtime_setting.go`（新增）：`RuntimeSettingOverride` 内存覆盖快照（`atomic.Value`，conf 保持零依赖）；`EffectiveSubAgentConfig(override)` 收敛「覆盖合并 + 默认值归一化」为唯一实现。
- `conf/config.go`：`GetReactRuntimeConfig` 的 subagent 归一化段替换为 `EffectiveSubAgentConfig(GetRuntimeSettingOverride().SubAgent)`。
- `service/setting/setting.go`（新增）：Get/Update 服务 + 范围校验（maxParallel 1-8、defaultMaxSteps 1-64、maxDepth 1-4）+ `clearFields` 清除覆盖语义 + `Bootstrap/Shutdown` TTL 刷新（10s，拉平多实例漂移；刷新失败保留上一份快照，不闪断回 yaml）。写路径落库后本进程立即刷新快照。
- `controllers/http/setting/setting.go` + `router/http.go`：`POST /setting/subagent/get|update`（跟随既有管理接口鉴权与渲染模式）。
- `service/react/runtime.go:461`、`service/react/execution_profile.go`：两处 `conf.CustomConf.LLM.React.SubAgent.*` 直读统一改经 `conf.GetReactRuntimeConfig()`，消除双口径（否则面板改了开关但 agent 清单仍按 yaml 装配）。
- `components/params/setting.go` + `components/error.go`（6100001）：请求/响应结构（effective + 逐字段 source + override 原文）与错误码。
- `web/react/index.js` + `index.css`：管理面板新增「运行时配置」Tab（cardKind=setting 自定义渲染）：每字段「覆盖小开关 + 值控件 + 来源徽标（覆盖/yaml/默认·生效值）」、保存/放弃修改、审计信息与生效时机说明。

## 3. 影响范围

- 接口：新增 2 个 `/setting/*` HTTP 端点；无 WS 协议变更。
- 数据库：新增 1 张表（`sql/runtime_setting_v1.sql` 可重复执行；存量环境需执行）。
- 配置：不新增 YAML 字段；`subagent.*` yaml 语义不变（降级为兜底基线）。
- 行为兼容：无 DB 行/无覆盖时 `GetReactRuntimeConfig` 输出与改动前完全一致；`service/react` 全量测试通过。
- 生效语义：保存后新 run / 下一次委派生效，运行中 run 不受影响；多实例约 10 秒内拉平。

## 4. 测试

- `conf/runtime_setting_test.go`：字段级覆盖合并、nil 无操作、覆盖值绕过默认值归一化。
- `service/setting/setting_test.go`：范围校验（含 clear 跳过校验、未知字段拒绝）、增量合并/clear 优先/显式关闭区分/空现状、来源徽标判定。
- 全量 `go test ./...` 通过（24 包）；`gofmt`/`go vet` 干净（新文件 LF；工作区 CRLF 为 autocrlf 环境噪音）。
