# 新增文档维护技能与文档基线

## 1. 背景与目标

项目已有多篇架构、方案、调研和学习文档，但主要平铺在 `docs/` 根目录，缺少统一元信息、系统文档索引和自动校验。本次引入文档维护 Skill，并建立不破坏既有文档的渐进式治理基线。

## 2. 代码改动

- `skills/bootstrap-project-docs/`：加入项目文档体系初始化 Skill 及参考模板。
- `skills/writing-changelog/`：加入变更记录和整合 Skill 及参考模板。
- `docs/CONVENTION.md`：定义文档分类、模块枚举、front-matter、保留策略和整合规则。
- `docs/README.md`、`docs/system/README.md`、`docs/changelog/README.md`：建立索引。
- `docs/system/react_runtime.md`、`docs/system/skill.md`、`docs/system/memory.md`：按 `main` 当前代码建立首批系统文档。
- `scripts/check-docs.sh`：校验新增受管目录；历史平铺文档暂不强制迁移。

## 3. 影响范围

- 接口：不修改运行接口和管理接口。
- 配置：不新增运行时 YAML 配置。
- 数据库：不新增数据表，不执行数据迁移。
- 既有文档：全部保留原路径和原内容。

## 4. 测试验证

- `bash scripts/check-docs.sh`：检查 `docs/system/` 与 `docs/changelog/` 新建受管文档。
- Skill 内容来自 `doc-skills.zip`，保留两份 Skill 的 `SKILL.md` 与 reference 目录。

## 5. 风险与兼容性

校验脚本不扫描既有 `docs/` 根目录文档，因此不会因历史文档缺少 front-matter 阻塞当前仓库。后续旧文档是否归档或合并仍由人工决定。
