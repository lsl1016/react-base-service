# 会话删除（硬删级联）

## 背景

会话历史只有切换与新建，无法删除——长期使用后历史堆积，无用会话无法清理。

## 行为约定（与用户确认）

- **硬删**：单事务内级联删除该会话全部关联数据，不可恢复（前端二次确认兜底）。
- **运行中的会话一律拒绝**：`HasActiveReactRunWithDB` 命中即返回明确错误
  （"会话有正在运行的任务，请先停止后再删除"）——避免与执行中的 run goroutine 竞争。
  不提供"停止并删除"组合操作。
- **归属校验**：复用 `validateReactSessionContext` 五元组口径，只能删自己的会话。
- **一期不动物理文件**：上传附件、沙箱产物只删 DB 行（文件记录可能被多处引用，
  物理清理需引用计数，留待后续）。

## 改动

### 后端

- `POST /react/session/delete`（`params.ReactSessionDeleteReq{sessionId, callerKey, routeValues}`），
  响应携带各关联表删除行数（排障友好）。
- `service/react/session_delete.go`：行锁 → 归属校验 → 活跃 run 拒绝 → 级联删除
  （Plan 子表按 plan_execution_id IN 先删，随后 tool_result / pending_input /
  run_feedback / artifact / async_task / message / run / session）。
- Steering 排队账本随 tblLlmReactPendingInput 一并删除，队列不残留孤儿。

### 前端（SDK）

- `AgentClient.deleteSession(sessionId)`：REST 调用 + 本地清理三件事——
  dispose 该会话 runtime（多会话架构下可能是挂空闲连接的后台会话）、
  `ledger.clearSession` 清 IndexedDB、删的是当前视图会话时自动切到新会话草稿。
- SessionList 每项 hover 显示删除按钮（垃圾桶图标）；**运行中的会话按钮禁用**
  （title 提示先停止任务）；点击进入**行内二次确认**（"不可恢复" + 确认/取消，
  与 QueueStrip 编辑交互风格一致）；删除成功刷新列表与徽标。
- 新增 UI 事件 `session_delete`（previousSessionId + sessionId）。

## 验证

- 后端 e2e（真实 MySQL，`REACT_SESSION_DELETE_E2E=1 go test ./service/react/ -run TestDeleteReactSessionE2E`）：
  活跃 run 拒绝且零删除、归属不匹配拒绝、正常删除级联清空（runs/messages/pending 计数与表行数核对）、
  删除不存在会话报错。
- 前端 `vitest run` 全量通过（含 deleteSession 删当前会话切草稿、删后台会话不影响当前视图两用例）。
