# 文档整理与技能本地化计划（2026-09-19）

执行技能：`.agents/skills/bootstrap-project-docs`（增量模式）。
前置基线：commit `3842e99` 已建立 `docs/CONVENTION.md`、`docs/system/`（3 篇）、`docs/changelog/`、`scripts/check-docs.sh`。

## 背景与目标

1. `docs/CONVENTION.md` 的模块枚举定义了 17 个模块，`docs/system/` 只覆盖 `react_runtime`、`skill`、`memory` 3 篇，缺 13 篇模块文档。
2. 项目技能 `.agents/skills/` 的参考模板来自原项目（bw-go / 蓝鲸），存在信息暴露，需替换为本项目真实内容。
3. `docs/CONVENTION.md`、`docs/README.md` 引用的 `skills/...` 路径不存在，实际路径为 `.agents/skills/...`。

## 范围与约束

- **不删除、不移动 `docs/` 根目录下的平铺文档**（架构、方案、调研、学习记录保持原路径原内容）。
- 新增文档只写入 `docs/system/<模块名>.md`；本计划文件写入 `docs/plan/`。
- 不改动业务代码。
